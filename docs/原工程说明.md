# 画中游 HuaZhongYou

PICO Project Swan 上的全沉浸名画游览：坐着的玩家面前展开两幅宋代名画，卷一张择端《清明上河图》、卷二王希孟《千里江山图》。每一段画都立在面前的弧形画墙上，按远景、中景、近景分成三层不同深度（从座位看严丝合缝，头一动就有立体感，2.5D）；在画里找东西、把掉出画面的画片放回去、回答小问题，每段都有语音讲解。卷二还有一个研色小作坊：研磨矿石、水飞分层、给小山上青绿颜色。

> 2026-11-18 v0.3.3（versionCode 8）：当前提交版本，真机测试 2026-11-18 通过。0.2 以后每一段都是可以走进去的立体小景（「走进画里」），各版本的改动见 `更新说明.md`。

> 2026-11-10 v0.1.1（versionCode 2）：千里江山图「研色」一节的乳钵换成 3D 瓷乳钵模型。详见 `更新说明.md`。

> 2026-11-09 v0.1（versionCode 1）：第一版，已在服务器上编译并通过单元测试。
> - 卷一《清明上河图》6 段：汴京郊野（驮炭的毛驴）、汴河漕运（卸货的大船，放回篷船）、虹桥（放桅杆的大船）、城外街道（牛拉的大车，放回十千脚店的彩楼）、城门（骆驼队）、孙羊正店（彩楼欢门、宋代夜市）。
> - 卷二《千里江山图》4 段：少年王希孟（江边的亭子、十八岁）、长桥（桥心有亭的长桥、矿物颜料）、山居（瀑布，放回一座青山）、研色（研石绿、水飞分层、头青二青三青、给小山上色：赭石打底、石绿铺山腰、石青压山顶）。
> - 操作：找东西是看着画捏一下；画片要捏住不放，拖到墙上的空白处，从座位看对齐了再松手；研色时捏住研杵、小棒在碗里来回拖，把颜料碟拖到小山上要画的那一层。
> - 星级：每段不失误三星，失误不超过 2 次两星（提示算一次失误）。奖杯是三枚印章：游完卷一得铜印「游」，两卷都游完得银印「览」，每段三星得金印「珍」，并开放隐藏的「上元夜游虹桥」（虹桥一段变成夜景，河上升起孔明灯、放烟花）。
> - 讲解：开场白和 10 段各一段语音（ListenHub，声音 huibennulaoshi），进入一段时自动播放，面板上可重听或停止。
> - 自动测试 4 个：每段都能三星游完、失误扣星、段落按顺序开放且两卷一开始都能进、要找的地方和掉出的画片都在画面内且互不重叠。
> - 调试钩子 AutoPilot（logcat 标签 HuaTest，只在 debug 包里）：`walk` 依次游完两卷，另有 `open`、`solve`、`grant`、`night`、`view`、`reset`。
> - 待验证：模拟器上的画面和自动游览；真机上画墙的大小和距离、三层景深的效果、拖画片的手感。

> 2026-11-10 模拟器验证：两卷十段全部游完，30/30 星，没有闪退。模拟器上修好三处：开局在后台线程设光照导致闪退；画墙在研色台初始化之前被用到导致闪退；找到的东西「走出来」后销毁时把整段画的贴图也释放了，下一段闪退（现在整段共用一份材质，离开时才释放）；另外画面原来上下颠倒，已改正（文件贴图的第一行也在 v = 1）。

## 构建

```
cd app
JAVA_HOME=~/.pico/primer-cli/jdk/jdk-21.0.12.1+1 ./gradlew --no-daemon testDebugUnitTest assembleDebug assembleRelease
```

画面素材由 `tools/make_sections.py` 从公有领域的高清扫描切出（见 `docs/素材来源.md`），语音由 `../../tools/narration/make_narration.py` 按 `tools/narration/clips.tsv` 录制。安装包在 `apk/`。
